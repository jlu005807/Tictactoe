# 井字棋（TicTacToe）

本项目是一个基于C++和Visual Studio开发的井字棋（TicTacToe）小游戏，支持玩家对战，拥有简洁的图形界面。

## 主要功能
- 玩家对战井字棋
- 图形化棋盘与棋子显示
- 胜负判断与提示
- 简单易用的操作界面

## 编译与运行
1. 使用 Visual Studio 2022 打开 `Tictactoe.sln` 解决方案文件。
2. 选择“生成”菜单，点击“生成解决方案”即可编译。
3. 编译完成后，可在 `x64/Debug/` 或 `x64/Release/` 目录下找到可执行文件 `Tictactoe.exe`。

## 资源说明
- 棋盘与棋子图片等资源位于 `Tictactoe/src/` 目录。
- 安装包与相关文件位于 `Tictactoe_Setup/Release/`。
